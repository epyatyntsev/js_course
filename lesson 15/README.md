# Заняття 15. Асинхронність у JavaScript

## Коротко про урок

На цьому занятті ви дізнаєтесь, як JavaScript працює з операціями, що потребують часу: таймерами та запитами до сервера. Ми пройдемо три рівні асинхронності — від `setTimeout` через `Promise` до `async/await`.

## Що є в `index.js`

- порядок виконання: синхронний код завжди перед кодом із `setTimeout`
- `setTimeout` і `clearTimeout` — відкладене виконання та його скасування
- `new Promise` з `resolve` і `reject` — ручне створення промісу
- `.then()` і `.catch()` — обробка результату та помилки
- `async/await` з `try/catch` — той самий код, але читабельніший
- `fetch` — запит до API, перевірка `response.ok`, обробка 404
- `Promise.all` — три запити паралельно замість трьох по черзі
- вимір часу через `Date.now()` — видима різниця між двома підходами

## Що варто запам'ятати

- `setTimeout(fn, ms)` — виконає `fn` **не раніше** ніж через `ms` мілісекунд
- синхронний код виконується першим, навіть якщо в `setTimeout` вказано `0`
- `new Promise((resolve, reject) => ...)` — `resolve` для успіху, `reject` для помилки
- `.then()` можна ланцюжити: значення з `return` потрапляє в наступний `.then()`
- `async` перед функцією означає, що вона повертає проміс
- `await` ставить на паузу **тільки свою функцію**, а не всю сторінку
- у `fetch` потрібні два `await`: перший на відповідь, другий на `response.json()`
- `fetch` **не кидає помилку** на 404 чи 500 — перевіряйте `response.ok` вручну
- `Promise.all` запускає операції одночасно: три запити по 400 мс — це 400 мс, а не 1200 мс

## Домашнє завдання

1. Напиши функцію `wait(ms)`, яка повертає проміс і вирішується через вказану кількість мілісекунд. Використай її, щоб вивести три повідомлення з паузою в секунду між ними.
2. Напиши `async`-функцію, яка завантажує пост з `https://jsonplaceholder.typicode.com/posts/1` і показує його заголовок на сторінці. Не забудь перевірити `response.ok`.
3. Додай до попереднього завдання індикатор завантаження та повідомлення про помилку. Перевір, що помилка справді показується — запроси пост з id `9999`.
4. Зроби кнопку, яка через 3 секунди змінює текст на сторінці, і другу кнопку, яка скасовує цей таймер через `clearTimeout`.
5. Завантаж пости з id 1, 2 і 3 двома способами: спочатку по черзі через `await`, потім разом через `Promise.all`. Виведи в консоль час обох підходів і порівняй.
