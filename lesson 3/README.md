# Заняття 3. Оператори

## Коротко про урок

На цьому занятті ви познайомитеся з операторами в JavaScript. Розберете арифметичні оператори, оператори порівняння та логічні оператори, а також побачите, як вони працюють у простих прикладах.

## Арифметичні оператори

Арифметичні оператори використовують для роботи з числами.

### Основні арифметичні оператори

- `+` додавання
- `-` віднімання
- `*` множення
- `/` ділення
- `%` остача від ділення
- `**` піднесення до степеня

### Приклади

```js
console.log(10 + 5);  // 15
console.log(10 - 5);  // 5
console.log(10 * 5);  // 50
console.log(10 / 5);  // 2
console.log(10 % 3);  // 1
console.log(2 ** 3);  // 8
```

## Оператори порівняння

Оператори порівняння допомагають порівнювати значення між собою.

Результат такого порівняння завжди буде `true` або `false`.

### Основні оператори порівняння

- `>` більше
- `<` менше
- `>=` більше або дорівнює
- `<=` менше або дорівнює
- `==` дорівнює без суворої перевірки типу
- `===` сувора рівність
- `!=` не дорівнює без суворої перевірки типу
- `!==` сувора нерівність

### Приклади

```js
console.log(10 > 5);     // true
console.log(10 < 5);     // false
console.log(10 >= 10);   // true
console.log(8 <= 5);     // false
console.log(5 == "5");   // true
console.log(5 === "5");  // false
console.log(5 != "5");   // false
console.log(5 !== "5");  // true
```

## Логічні оператори

Логічні оператори використовують, коли потрібно поєднати кілька умов або змінити логічне значення.

### Основні логічні оператори

- `&&` логічне І
- `||` логічне АБО
- `!` логічне НЕ

### Приклади

```js
console.log(true && true);   // true
console.log(true && false);  // false
console.log(true || false);  // true
console.log(false || false); // false
console.log(!true);          // false
console.log(!false);         // true
```

## Що варто запам'ятати

- арифметичні оператори працюють з числами
- оператори порівняння повертають `true` або `false`
- логічні оператори допомагають працювати з умовами
- `===` і `!==` краще використовувати частіше, ніж `==` і `!=`
