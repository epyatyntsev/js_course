# Заняття 7. Масиви та методи роботи з ними

## Коротко про урок

На цьому занятті ви познайомитеся з масивами як колекціями даних і базовими методами роботи з ними: `map`, `filter`, `find`, `includes`.

## Що є в `index.js`

- створення масивів
- доступ до елементів за індексом
- властивість `length`
- базові зміни масиву через `push`, `pop`, `unshift`, `shift`
- перевірка наявності значення через `includes`
- створення нового масиву через `map`
- фільтрація елементів через `filter`
- пошук одного елемента через `find`
- робота з масивами рядків і чисел
- комбінування `filter` і `map`
- практичні приклади зі студентами, оцінками, цінами, ролями та статусами

## Що варто запам'ятати

- масив зберігає список значень
- індекси в масиві починаються з `0`
- `map` повертає новий масив такої самої довжини
- `filter` повертає новий масив тільки з елементами, які пройшли перевірку
- `find` повертає перший знайдений елемент або `undefined`
- `includes` перевіряє, чи є значення в масиві
- методи масивів часто використовують разом зі стрілочними функціями

## Домашнє завдання

1. Створи масив з іменами студентів і перевір наявність одного імені через `includes`.
2. Створи масив чисел і через `map` отримай новий масив подвоєних чисел.
3. Через `filter` отримай тільки числа більші за 10.
4. Через `find` знайди першу ціну меншу за певну суму.
5. Створи масив статусів і перевір, чи є серед них статус `paid`.
