# JavaScript Course

Це курс з JavaScript для початківців.

У цьому репозиторії кожен урок знаходиться в окремій папці. У папках уроків ви знайдете короткий опис теми, приклади коду для розбору та додаткові матеріали.

## Як користуватися цим репозиторієм

1. Відкрийте папку потрібного уроку.
2. Прочитайте `README.md`, щоб зрозуміти тему заняття.
3. Перегляньте приклади в `index.js`.
