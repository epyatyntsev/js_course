# Заняття 13. Події та зміна стану

## Коротко про урок

На цьому занятті ви навчитеся реагувати на дії користувача через події браузера, змінювати стан у відповідь на ці дії та одразу відображати зміни на сторінці.

## Що є в `index.js`

- поняття події та обробника (event listener)
- подія `click` — кнопка і лічильник
- подія `input` — живий preview при введенні
- подія `change` — вибір зі списку
- подія `keydown` — реакція на клавіші
- зв'язок: подія → зміна стану → оновлення UI
- лічильник з кнопками + відображення на сторінці
- форма з live-валідацією
- список задач — додавання та відмічання

## Що варто запам'ятати

- `addEventListener(тип, функція)` — підписка на подію
- функція-обробник отримує об'єкт `event` з деталями події
- `event.target` — елемент, на якому сталася подія
- `event.target.value` — поточне значення поля вводу
- зміна стану завжди супроводжується оновленням DOM
- цикл: подія → оновити стан → перемалювати UI

## Домашнє завдання

1. Зроби кнопку, яка змінює колір фону сторінки при кліку.
2. Зроби поле вводу, яке в реальному часі показує кількість введених символів.
3. Зроби список із чекбоксами — при кліку задача відмічається як виконана.
4. Зроби форму з кнопкою «Додати» — новий елемент з'являється у списку.
5. Зроби кнопку «Скинути» — список очищується і стан повертається до початкового.
