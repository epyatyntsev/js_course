# Заняття 11. Поняття стану (state)

## Коротко про урок

На цьому занятті ви дізнаєтеся, що таке стан програми, як дані змінюються з часом і чому зміна стану має наслідки для всієї програми.

## Що є в `index.js`

- стан як окремі змінні
- зміна стану та читання нового значення
- стан як об'єкт
- стан інтерфейсу (відкрите меню, активна вкладка, завантаження)
- лічильник — класичний приклад стану
- стан форми та перевірка валідності
- похідний стан — значення, що обчислюються зі стану
- історія змін стану

## Що варто запам'ятати

- стан — це дані, які змінюються з часом під час роботи програми
- кожна зміна стану може впливати на те, що бачить користувач
- зручно зберігати пов'язані дані як один об'єкт стану
- похідний стан не зберігається окремо — він обчислюється зі стану щоразу
- зміни стану краще робити через функції, а не напряму

## Домашнє завдання

1. Створи об'єкт стану для профілю користувача з іменем, email і статусом онлайн.
2. Напиши функції для зміни кожного поля стану та виводь стан після кожної зміни.
3. Створи масив товарів у стані та порахуй загальну суму через `reduce`.
4. Додай до стану поле `lastUpdated` і оновлюй його при кожній зміні.
5. Реалізуй просту функцію `undo`, яка повертає стан до попереднього значення.
