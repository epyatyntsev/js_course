# Заняття 5. Функції

## Коротко про урок

На цьому занятті ви познайомитеся з базовими функціями в JavaScript. Розберете, як оголошувати функції, як викликати їх, як передавати параметри та як повертати результат через `return`.

## Що є в `index.js`

- оголошення функцій через `function`
- виклик функцій
- функції без параметрів
- функції з одним і кількома параметрами
- повернення значення через `return`
- використання результату функції у змінній
- базові приклади з числами, рядками, умовами та розрахунками
- приклади повторного використання функцій

## Що варто запам'ятати

- функція дозволяє зберегти блок коду і викликати його багато разів
- параметри потрібні, щоб передавати дані всередину функції
- `return` повертає результат з функції назовні
- після `return` функція завершує виконання
- одна функція може викликати іншу функцію

## Домашнє завдання

1. Створи функцію, яка вітає користувача за іменем.
2. Створи функцію, яка додає два числа і повертає результат.
3. Створи функцію, яка перевіряє вік користувача.
4. Створи функцію, яка рахує фінальну ціну товару зі знижкою.
5. Створи функцію, яка повертає оцінку за кількістю балів.
