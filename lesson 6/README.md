# Заняття 6. Функції: поглиблення

## Коротко про урок

На цьому занятті ви поглибите тему функцій у JavaScript. Розберете стрілочні функції, базове поняття чистих функцій і побічні ефекти.

## Що є в `index.js`

- порівняння звичайних і стрілочних функцій
- короткий синтаксис стрілочних функцій
- стрілочні функції з одним і кількома параметрами
- функції з умовами
- приклади чистих функцій
- приклади функцій з побічними ефектами
- робота із зовнішніми змінними
- приклади з масивами
- приклад простого сховища як побічного ефекту

## Що варто запам'ятати

- стрілочні функції часто використовують для коротких функцій
- якщо у стрілочної функції один короткий вираз, результат можна повернути скорочено
- чиста функція повертає однаковий результат для однакових аргументів
- чиста функція не змінює зовнішні дані
- побічний ефект — це зміна або дія поза поверненням результату
- побічні ефекти не завжди погані, але їх треба контролювати

## Домашнє завдання

1. Перепиши кілька звичайних функцій зі старих уроків у стрілочні.
2. Створи чисту функцію для розрахунку фінальної ціни товару.
3. Створи чисту функцію, яка повертає новий масив без зміни старого.
4. Створи приклад функції з побічним ефектом.
5. Поясни словами, чим чиста функція відрізняється від функції з побічним ефектом.
