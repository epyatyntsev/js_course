# Заняття 8. Об'єкти та копіювання даних

## Коротко про урок

На цьому занятті ви познайомитеся з об'єктами в JavaScript, оператором розгортання `spread` та копіюванням масивів і об'єктів.

## Що є в `index.js`

- створення об'єктів
- доступ до властивостей через крапку
- доступ до властивостей через квадратні дужки
- зміна та додавання властивостей
- масиви об'єктів
- копіювання масивів через spread
- копіювання об'єктів через spread
- створення оновленого об'єкта без зміни старого
- поняття поверхневої копії
- копіювання вкладеного об'єкта вручну

## Що варто запам'ятати

- об'єкт зберігає дані у форматі ключ-значення
- властивість об'єкта має назву і значення
- spread дозволяє розгорнути масив або об'єкт
- копія через spread є поверхневою
- якщо всередині об'єкта є інший об'єкт, його треба копіювати окремо
- копіювання допомагає не змінювати початкові дані напряму

## Домашнє завдання

1. Створи об'єкт користувача з іменем, віком і містом.
2. Додай до об'єкта нову властивість.
3. Створи копію об'єкта через spread і зміни одну властивість у копії.
4. Створи масив товарів у вигляді об'єктів.
5. Через `map` створи новий масив товарів з додатковою властивістю.
